# Owe It

Accountability app: put money on your goals, pick judges, and track progress.

## Development

```bash
npm install
npm run dev
```

Build and preview:

```bash
npm run build
npm run preview
```

## Stack

Vite, React, TypeScript, Tailwind CSS, Supabase, Stripe.
